DELIVERY EXPECTATION
One coordinated build effort includes implementation, tests, repair and APK assembly. A single brief does not guarantee unlimited uninterrupted execution. The output must include a usable APK, the matching newly authored source, build instructions, actual evidence and all remaining limitations.

A chat-only session can read the brief and author files. Actual APK assembly and runtime checks require an execution environment with Android build tools; unavailable tools must be reported rather than simulated. Use Claude Code for the connected implementation effort. This brief does not assume unlimited Pro usage or require a separate application API account for local editing.
